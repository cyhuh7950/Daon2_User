## 5. 되돌리기 방법

1. 기능 코드: 시작 기준 `ddb70040` 이후 WO-N1 커밋을 되돌리는 커밋(`git revert`)을 만들어 PR Broker로 병합한다. 그다음 ysna에서 `bash deploy/daon2-user/ysna-deploy.sh`(기본: api·web·작업자 3종 모두)로 배포한다.
2. DB: 0084~0087 테이블은 남겨 둔다. 새 테이블만 더한 것이라 이전 코드와 함께 있어도 동작에 영향이 없다. downgrade는 행이 있으면 막히도록 되어 있어 강제하지 않는다.
3. 일부 기능만 되돌릴 때는 해당 단위의 커밋(CHECK 표의 브랜치·커밋 칸)만 되돌린다.
4. 배포 주의: 배포 스크립트에 `api`·`web`만 지정하면 문서·스튜디오 작업자는 다시 올라오지 않는다. 작업자 코드가 바뀐 되돌림은 작업자도 지정하거나 인자 없이 배포한다.
