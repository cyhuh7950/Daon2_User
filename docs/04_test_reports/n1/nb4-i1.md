## 발견한 결함

- N1-B08: 도구를 끈 질문 하나가 TEXT_GENERATION_GROUNDING_INVALID로 실패(로그 reason=insufficient_with_citation). 모델이 일부만 답하면서 insufficient=true와 인용을 함께 보냄. main d30e3966에서 고침. 재배포 뒤 같은 질문은 실패 없이 "근거 부족" 안내로 끝남. 이번 응답이 보정 경로를 실제로 거쳤는지는 API 로그에 경고가 남지 않아 미확인(단위 시험 2건으로 확인).

## 확인한 점

- 연결 실패·문서 추가 실패·TXT 이해 실패의 진단 로그는 도구 이름·오류 코드·이유 종류만 남기고 검색어·본문은 남기지 않는다.
- 2 MiB 소스 실제 처리 시간은 따로 재지 않았다(256KB 문서 처리는 수십 초 안).
