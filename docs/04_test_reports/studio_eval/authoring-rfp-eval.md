# 작성 엔진(RFP 대응 제안서) 평가 — 자동 측정 + 수동 채점표

- 실행: 합성 RFP 2건 × 기존 제안서 3건, 가상 MCP 서버, 설정된 기본 모델/Provider 우선순위 사용
- 아래 자동 측정값은 합성 코퍼스의 정답(RFP의 REQ 항목)과 비교한 것이다. '사람 채점' 칸은 평가자가 채운다.

## 해석 가이드

- 재현율·정밀도는 REQ-번호가 붙은 정답과의 어휘 유사도(≥0.7)로 센 값이라 사람이 추가한 요구사항 표현 차이는 오차로 잡힌다.
- 대응표는 어휘 중복 기반 판정이라 표본 확인이 필요하다. 모델·Provider는 워크스페이스 설정에 따른다.
