## 3. 기능별 검증 근거

### 3.1 Studio v2 산출물 9종 + 메모 + 작성 문서
- E2E(실제 LLM): 유형별 생성·상세·provenance·내보내기·근거 콘텐츠. 모든 내보내기 형식을 실제 파일로 저장해 검증.
- **파일 열기(실제 앱 실행)**: `report.docx` Word 열기(2쪽, 표 1, 제목 3, 한글), `slides.pptx` PowerPoint 열기(10장 모두 글자 있음, PNG 렌더 확인), `data_table.xlsx` Excel 열기(시트 2개, 머리글 확인). PDF 7개 쪽수·한글 글자 추출, PNG 해상도, SVG 파싱, CSV(UTF-8 BOM·한글), JSON.
- 실제 앱 화면: 9개 카드 열기, 보고서(근거 8), 표(24 근거), 슬라이드(10장 탐색), 마인드맵(노드 41개·확대/축소), 퀴즈(10문항 정오·해설·결과 3/10·틀린 문항 7), 플래시카드(뒤집기·집계·모르는 카드만 2/12), 이름 바꾸기, 프롬프트 및 소스 보기, 공유, 삭제 확인(취소 시 유지), DOCX·PDF·MD 내려받기(올바른 MIME·파일 이름).

### 3.2 오디오 개요 / 동영상 개요 / TTS 엔진 관리
- 생성 E2E: 오디오(약 70~87초 분량), 동영상(4~5장면, 47~96초), 화면 등록 엔진으로 생성, 정책 차단·마스킹.
- **음성 인식 왕복**: whisper로 다시 인식해 대본 대비 유사도(숫자는 한국어 수 읽기로 통일) 오디오 94.7~97.5%, 동영상 95.6~98.1%, 장면별 80% 미만 없음, 동영상 오디오 길이와 본문 길이 일치.
- 동영상 파일: H.264 1280x720 + AAC, mp4 챕터 수·제목·길이 본문과 일치, 자막(VTT) 시간 단조·영상 길이 안.
- **실제 앱 재생**: 오디오 72초 로딩, 대본 줄 클릭 시 이동·현재 줄 강조·재생, 속도 1.5×; 동영상 1280x720·자막 트랙 17줄 표시·챕터 클릭 이동·재생.
- 관리 API(BFF): 권한 부여 전 403 5/5 → 승인된 임시 관리자 지정 후 등록·확인·수정·기본·사용 안 함·해제 24항목 통과 → 원복 후 다시 403.

### 3.3 접근성·반응형·테마(실제 앱에서 측정)
- 글자 대비: 라이트·다크 모두 목록과 5개 뷰어(보고서·표·퀴즈·오디오·동영상)에서 위반 0(수정 후).
- 휴대폰 폭 375px: 9개 뷰어 모두 가로 넘침 없음, 하단 탭 3개(높이 44px).
- 색약 시뮬레이션(Machado 2009): 일부 색 쌍은 색약 시각에서 구분이 어려움(ΔE 0~3). **색만으로 구분하지 않음** — 유형 아이콘 9종 모양이 모두 다르고 이름 글자가 항상 함께 표시됨.
- 키보드·포커스: 대화상자 `aria-modal`·이름 있음, 열릴 때 포커스가 안쪽, Esc로 닫히고 포커스가 트리거(⋮)로 복귀. 이름 없는 상호작용 요소 0(숨김 파일 입력 제외), 랜드마크 `main` 1·`nav` 1, 제목 h1→h2→h3 구조, 문서 언어 `ko`.

| 관리자 계정으로 **설정 화면을 직접 눌러 보기**(TTS 엔진 등록 등) | 비관리자 계정의 접근 제한 화면과 관리 API E2E는 확인. 화면 클릭 흐름은 시험 페이지(가짜 데이터)와 컴포넌트 시험으로 확인 |

## 7. 기준선부터 실패하던 시험(이번 작업과 무관)

node 시험 102건(기본 환경)은 **작업 시작 시점의 커밋에서도 실패**했고(당시 104건) 이번에 새로 생긴 실패는 없다. 주요 원인:
- 조직 콘솔·가입·전환(J2·J3·L3) 계열: 시험이 **특정 임시 폴더만 쓰도록 거는 환경 가드**(예: `D:\tmp\daon2-user-s39-l3-20261017-eoul2`) 때문에 이 PC에서는 시작 즉시 실패한다. 가드가 요구하는 폴더로 TEMP를 지정하면 L3 28/28이 통과하고 전체 실패가 102 → 73으로 줄었다(확인함).
- 남은 73건: 다른 가드 폴더를 요구하는 J2·J3 시험, iOS·macOS 워크플로, 기존 사용자 매뉴얼 PDF 동일성, Provider 화면 스크롤, 레거시 Studio(S22) 등 이전 프로젝트에서 가져온 시험. Studio v2·TTS·오디오·동영상과 무관하다.
- 이 시험들을 지울지, 가드를 새 환경에 맞게 고칠지는 사용자 결정이 필요하다(개발 측은 임의로 지우지 않았다).
